# v0.2 — Wire factor into dependency chain

**Date:** 2026-07-27  
**Status:** Implemented  

## Problem

Activated side-branch nodes (e.g. `process_capacity`) had live predictives but did not affect `outcome` until a child depended on them.

## Solution

- `GraphStore.wire_parent(parent_id, child_id, weight)`
- `POST /graphs/{id}/nodes/{parent_id}/wire` with `{ child_id, weight }`
- UI: on active node, **Wire into selected → re-sim**

## Acceptance

1. Activate a proposed factor  
2. Wire it into `process_stage` (or other downstream)  
3. Graph edge appears; re-sim runs  
4. Changing the factor’s parameters moves downstream quantiles after save  

## Out of scope

- Auto-rewire on activate  
- Residual-triggered propose  
- Multi-user / cloud
