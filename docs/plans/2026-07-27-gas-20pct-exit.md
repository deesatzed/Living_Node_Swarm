# US Gas prices + 20% contract-price exit

**Date:** 2026-07-27  
**Use case:** Kalshi “US gas prices this week / tomorrow” style threshold markets (screenshot: Above 4.120 @ ~51%, etc.)

## Strategy (explicit)

1. **Market:** Binary YES = national avg gas **above** strike \(K\) (USD/gal).  
2. **LNS graph:** `aaa_national_avg`, `week_shock`, `threshold_usd`, `model_price_index`, `market_implied_yes`.  
3. **Entry (micro-stake):** Record journal at YES mid \(p_0\) (1 contract default). Place on Kalshi separately via MCP if desired.  
4. **Exit rule — SELL when YES mid moves 20%:**

\[
\frac{|p_{\mathrm{now}} - p_0|}{p_0} \ge 0.20
\]

Either direction (up or down). This is a **contract probability** move, not a 20% move in gas $/gal.

5. **Success metrics:** Brier vs resolution; vs mid freeze; optional tiny PnL.

## API

| Endpoint | Purpose |
|----------|---------|
| `POST /use-cases/gas/graph` | Seed gas graph (+ optional live ticker mid) |
| `POST /graphs/{id}/kalshi/refresh-mid?ticker=` | Update `market_implied_yes` |
| `POST /journal/positions` | Open journal entry |
| `POST /journal/positions/check-all-exits` | Flag sells |
| `POST /journal/positions/{id}/close` | Close journal after sell |

## UI

Panel **US gas (Kalshi) + 20% sell rule** on main app.

## Stake discipline

Project account ~$10; prefer 1 contract / ≤$2–3 notional; always preview live orders on Kalshi.

## Live trading (implemented)

| Endpoint | Behavior |
|----------|----------|
| `GET /kalshi/balance` | RSA-auth balance |
| `POST /kalshi/orders` | `confirm=false` preview; `confirm=true` places order (caps enforced) |
| `POST /kalshi/auto-sell-20pct` | Dry or live sell when journal 20% rule hits |

UI: Preview BUY → Confirm BUY (live) → Check 20% exits (dry) → Auto-SELL 20% hits (live).

Caps (settings): `kalshi_max_notional_usd=3`, `kalshi_max_contracts=3`.
